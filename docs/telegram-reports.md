# Платежи и отчёты в Telegram

Откройте подключённого бота и отправьте `/menu`.

- **Ближайшие платежи** — один неоплаченный период на карточке: сначала самый ранний срок, включая просрочки. Под карточкой — «Отметить оплату», «Назад», «Далее» и «Обновить». Количество и суммы по валютам относятся ко всему разделу, а не только к показанной карточке.
- **Просрочки** — такие же карточки только со сроком раньше рабочего дня сервера.
- После отметки оплаты эта карточка заменяется следующей. Если оплачена последняя, открывается оставшийся предыдущий платеж; когда список пуст, кнопки оплаты больше нет. Повторное нажатие старой кнопки не оплачивает новый платеж.
- **Отчёт за месяц** — изображение с планом, оплаченной частью, остатком к оплате и распределением по категориям. Кнопки RUB / USD / EUR и соседних месяцев обновляют то же сообщение. Команда `/report 2026-10 USD` открывает конкретный месяц и валюту.

Это план платежей и отметки команды, а не банковский баланс. Валюты не складываются и не конвертируются. Суммы на графике точные до копеек/центов; процент в кольце округляется до одного знака. Пять крупнейших категорий показаны отдельно, остальные объединены с сохранением полной суммы.

Изображение формируется в Go внутри приложения, без отправки данных внешнему сервису графиков. Портретный PNG 1080×1560 сохраняет крупные цифры и подписи в телефонном предпросмотре; пустой месяц отображается отдельно. Большие суммы уменьшают шрифт, длинные категории сокращаются по реальной ширине текста. Сглаживание работает только в границах конкретной фигуры, а не выделяет размер всего изображения для каждой полоски.

У бота нет отдельного входящего порта: он использует исходящие запросы и long polling Telegram API. Доступ к разделам есть у настроенного командного чата и привязанных личных аккаунтов. Право отметить оплату проверяется отдельно; старые кнопки под напоминаниями продолжают работать.

Проверки:

```sh
go test -race ./internal/app/report ./internal/app/bot ./internal/app \
  -run 'TestRender|TestTopCategories|TestReport|TestTelegramMenuPagination|TestTelegramPaymentCard|TestTodoAndOverdue|TestMessenger' -count=1
go test ./internal/app/report -run '^$' -bench '^BenchmarkRenderMonthlyReport$' -benchmem
```
