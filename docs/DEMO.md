# Сценарий защиты

Подготовьте локальный запуск по README. Для реального Telegram заранее настройте собственные токен и чат; без них показывайте журнал как отключённый, не выдавая имитацию за доставленное сообщение.

1. **Администратор.** Откройте `/`, войдите с ADMIN_USERNAME/ADMIN_PASSWORD из `.env`. Покажите три отдельных итога валют и список.
2. **Новый платёж.** Добавьте «Демонстрация · сервер», 24 USD, срок завтра. Частота — ежемесячная. Так как осталось меньше 3 дней, проверка напоминания запускается сразу. При включённом Telegram покажите живое сообщение с названием, суммой, валютой и датой.
3. **Без дублей.** Откройте Журнал, дождитесь следующей фоновой проверки или обновите страницу. У периода останется одна отправка `sent`, в чате — одно сообщение. Не меняйте БД вручную для имитации успеха.
4. **Обычный пользователь.** Выйдите, войдите с DEMO_USERNAME/DEMO_PASSWORD. Кнопок создания платежа и управления командой нет. Отметьте оплату демонстрационного платежа сегодняшней датой. Изменяется только выбранный период.
5. **Просрочка.** В демоданных есть «Домен и почта» со сроком 4 дня назад. Подтвердите его сегодняшней датой: статус «Оплачено», но рядом со сроком сохранится 4 дня задержки.
6. **Исправление.** Нажмите «Изменить», поставьте фактическую дату равной сроку. Задержка исчезает, срок неизменен. Затем при желании отмените оплату — фактическая дата очищается, просрочка возвращается.
7. **Следующий период.** Перейдите к следующему месяцу. У демонстрационного платежа собственная неоплаченная запись; отметка предыдущего периода не скопировалась. История предыдущего месяца сохранена.
8. **Архив.** Снова войдите администратором. В «Регулярных» прекратите демонстрационный платёж. В списке он получит состояние «Архив», история оплат останется. После архивирования новые напоминания и периоды не создаются.
9. **Доступ и сохранение.** Покажите `/api/v1/docs`, спецификацию `docs/openapi.json`, выполненные тесты. Остановите только локальный процесс Ctrl+C, запустите снова — платежи и история на месте.

Для отдельной проверки 31-го числа автотест переводит контролируемые часы с 28 января на 31 марта и проверяет последовательность 31.01 → 28.02 → 31.03 → 30.04. Системное время компьютера или VDS менять не требуется.

## Карта требований

| Условие кейса | Реализация | Проверка |
|---|---|---|
| Закрытая панель и API | Cookie-сессия, закрытые HTML-шаблоны | `TestDataRequiresAuthorization` |
| Две роли | Проверки зависимостей API, UI по роли | `TestRegularUserPermissionsAndUserLifecycle` |
| Admin из .env | Виртуальная учётная запись id=0 | `TestAdminAccountCannotBeManagedInPanel` |
| CRUD обычных пользователей | Раздел «Команда», API | lifecycle-тест |
| Поля платежа | Название, Decimal-сумма, валюта, первый срок, monthly | тесты валидации |
| Периоды независимо от оплаты | Отдельная таблица occurrences | `TestMonthEndAnchorAndUnpaidIndependentPeriods` |
| 31-е и високосный год | Исходный anchor_day | тот же тест |
| Просрочка, исправление, отмена | Вычисляемые поля из двух дат | `TestPaymentDateCorrectionUndoAndDueDay` |
| RUB/USD/EUR отдельно | Целые центы, три отдельных итога | `TestCurrencySummaryExactAndDateFilters` |
| Напоминание за 3 дня | Сохраняемая очередь + фоновый поток | reminder-тесты |
| Позднее добавление | Фоновый проход сразу после создания | `TestImmediateReminderAfterCreate` |
| Отсутствие дублей | Уникальный ключ, claim-транзакции, uncertain | тесты двух workers, перезапуска, таймаута |
| Оплаченный/удалённый не напоминает | Повторная проверка под блокировкой | `TestPaidArchivedAndDisabledDoNotSend` |
| Сохранение истории | SQLite WAL + мягкое удаление | `TestArchiveAndRestartPreserveHistory` |
| Обязательные API | Маршруты `net/http` `/api/v1` | API-тесты + OpenAPI |
| OpenAPI и Swagger | Статический JSON и локальные ресурсы Swagger | `TestSwaggerIsLocalAndOpenAPIIsServed` |
| Передача решения | README, .env.example, bootstrap | `git archive` |

Дополнительно: календарь, журнал действий, журнал отправки, адаптивная панель. Email, webhook, вложения, кнопка оплаты внутри Telegram, произвольные частоты и годовой бюджет в эту версию не входят.
