# Соответствие кейсу Aeza: Invoice Keeper

Проверено по всем 18 страницам исходного кейса. Требования документа рассматриваются как предметная спецификация. Дополнительные инструменты эксплуатации — наша инженерная инициатива, а не скрытое обязательное условие кейса.

## Неочевидные вопросы, которые стоит объяснить жюри

- «Без дублей» при потере сетевого ответа — не повод повторять вслепую. `uncertain` требует проверки человеком. Строгое exactly-once с внешним API без его идемпотентного ключа гарантировать нельзя.
- Исправление даты оплаты не меняет срок; новый период не перезаписывает старый. Границы месяца считаются в едином `APP_TIMEZONE`, а не в часовом поясе браузера.
- Удаление, оплата и отправка сериализуются; важно проверять не только красивый UI, но и API, старые кнопки и параллельные нажатия.
- SMTP-сервис остаётся внешним: имя отправителя `aezakeeper`, реальный адрес — адрес разрешённого SMTP-аккаунта. Пустой `SMTP_TO` выключает общую копию, не личные письма.
- Резервная копия без проверки восстановления и без ключа шифрования не доказывает восстановимость. Учебное восстановление выполняется отдельно от production.
- Prometheus/Grafana наблюдают планировщик и результаты доставки отдельно от HTTP health. Kubernetes на одной VPS не устраняет единую точку отказа и не требуется кейсом.

## Живая демонстрация (около 7 минут)

1. Показать закрытый API без входа, войти администратором.
2. Создать тестовый ежемесячный платёж со сроком через 2 дня и получить Telegram-напоминание. Использовать понятное тестовое название, не настоящую оплату.
3. В боте открыть `/menu`, перейти в ближайшие, показать кнопку. Нажать «Оплачено» от привязанного аккаунта; повторное нажатие не создаст второй записи. Показать автора в журнале и независимый следующий период.
4. Войти обычным пользователем: сменить фактическую дату, снять/вернуть оплату; попытка админского API запрещена.
5. Показать просрочку, календарь, годовой бюджет и итоги в трёх валютах; прикрепить чек к одному периоду.
6. Показать доставку личного email и подписанный webhook в журнале, восстановимое удаление, Swagger.
7. Открыть Grafana через SSH: приложение доступно, планировщик работает, состояния отправок видны. Показать результат учебного восстановления. Объяснить ограничение одной VPS и план внешних резервных копий.

Не подменять живую проверку Telegram тестом с mock API: автоматические тесты доказывают логику, реальное нажатие дополнительно проверяет транспорт, аккаунт и конфигурацию.
